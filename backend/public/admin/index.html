Settings & Configuration
Telegram Bot Super Admin only
Orders are sent automatically via Telegram bot. Create a bot with @BotFather, get the token, then message your bot once to get your Chat ID via @userinfobot. The bot token is stored server-side only and is never sent back to this page.

Product photos: to include product images in order messages, set PUBLIC_BASE_URL in your .env to your live site address (e.g. https://yourstore.com). Photos can't be sent from a local localhost address — orders will then arrive as text only.
Notifications Overview

When an order changes status, automatically send a Telegram notification to your chat. Configuration is done below in the Telegram Bot section.

Status Updates: Automatic notifications sent when:
  • Order confirmed
  • Order processing
  • Order shipped
  • Order delivered
Minimum Order Amount
Set the smallest order total (in IQD) a customer can place. Orders below this are blocked with a message. Set to 0 for no minimum. This applies to the whole cart across all stores.
Sponsor Commission
Percentage of each sponsor's profit that the store takes as commission. The remaining amount goes to the sponsor. Default is 20%. Applies to all sponsors equally.

Sponsor Accounts
Create accounts for sponsor partners. A sponsor logs in at /sponsor/ and can add their own products and create one store category (their brand). They cannot see orders, settings, or other sponsors' products. Sponsor products are sold at the price they set (no store markup/profit applied).
